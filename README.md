# When Explanations Write Back

Public reproducibility repository for Aidan Edward Lawson's manuscript **When Explanations Write Back: Mechanistic Provenance and the Baseline Write Barrier**.

This repository contains the public-release manuscript and the reproducibility artifacts needed to inspect the PR-002 confirmatory record independently of the author's Hugging Face Jobs account.

## Confirmatory boundary

PR-002 produced an individual preregistered success on Phi-3.5-mini-instruct. The stronger preregistered cross-architecture gate was **not met** because Qwen and Mistral failed their calibration eligibility gates.
